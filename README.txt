This Github repository contains the codebase for the paper (LINK HERE).

it is organised in two sections : 
  -one dedicated to interacting with the Armpi_FPV robot, and using it to generate .csv folders containing commands and responses on the real robot. 
  -one dedicated to using a digital twin of said robot in Matlab for LSTM training, and for applying necessary post-processing on real data to make predictions.

Each section has a specific README for greater detail.
